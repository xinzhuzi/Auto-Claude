# 合并快速参考

> 一页纸速查

---

## 关键命令

```bash
# 进入项目目录
cd /Users/zhengbingjin/Project/Github/Auto-Claude

# 添加上游
git remote add local-upstream /Users/zhengbingbingjin/Project/temp/Auto-Claude
git fetch local-upstream

# 备份
git branch backup/pre-merge-$(date +%Y%m%d)

# 合并
git merge local-upstream/develop --no-commit

# 查看冲突
git status | grep "both modified"
```

## 回滚命令

```bash
# 合并中止
git merge --abort

# 回到备份
git reset --hard backup/pre-merge-YYYYMMDD

# 已推送回滚
git revert -m 1 HEAD
```
