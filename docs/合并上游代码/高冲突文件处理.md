## 2. `apps/frontend/src/main/terminal/terminal-manager.ts`

### 2.1 冲突分析

| 上游改动 | 本地改动 |
|----------|----------|
| XState terminal machine | 代理终端功能 |
| 账户感知会话持久化 | 终端颜色修改 |

### 2.2 解决策略

**优先采用上游版本**，因为:
- XState 重构是重大架构变更
- Bug 修复影响稳定性

### 2.3 合并步骤

```bash
# 采用上游版本
git checkout --theirs apps/frontend/src/main/terminal/terminal-manager.ts
git add apps/frontend/src/main/terminal/terminal-manager.ts
```

### 2.4 后续工作

如果本地有重要的定制功能，需要在合并后重新集成:
1. 记录本地定制功能
2. 合并完成后，基于新的 XState 架构重新实现

## 7. `apps/frontend/package.json`

### 7.1 差异对比

| 项目 | 上游 | 本地 | 合并策略 |
|------|------|------|----------|
| name | Auto-Claude | AI员工 | 保留本地 |
| version | 2.7.6 | 2.7.6-beta.5 | 使用上游 |
| productName | Auto-Claude | AI员工 | 保留本地 |
| dependencies | - | driver.js 等 | 合并 |

### 7.2 需要保留的本地依赖

```json
{
  "dependencies": {
    "driver.js": "^1.x.x",
    "reactflow": "^11.x.x",
    "react-resizable-panels": "^2.x.x"
  }
}
```

### 7.3 需要保留的本地配置

```json
{
  "build": {
    "win": {
      "target": ["nsis"],
      "arch": ["x64"]
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true,
      "installerIcon": "build/icon.ico",
      "uninstallerIcon": "build/icon.ico"
    }
  }
}
```

### 7.4 合并步骤

```bash
# 1. 查看双方版本
git show :2:apps/frontend/package.json > /tmp/ours.json
git show :3:apps/frontend/package.json > /tmp/theirs.json

# 2. 使用 jq 或手动合并
# - 版本号使用上游
# - name/productName 保留本地
# - dependencies 合并
# - build 配置保留本地

# 3. 安装依赖验证
cd apps/frontend && npm install

# 4. 验证构建
npm run build

git add apps/frontend/package.json apps/frontend/package-lock.json
```
