# 高冲突文件处理（本轮仅 1 个）

## 文件：`CLAUDE.md`

## 1. 冲突背景

- 上游新增了更完整的 Orchestrator-first 说明与 Context Management。
- 本地保留了若干中文规范（例如渐进式读写原则）。
- 二者都在同一区域改动，需人工合并。

## 2. 推荐合并原则

1. 结构优先：以 **上游最新结构** 为主骨架。
2. 规则保留：将本地仍有效的规范段落按章节合并回去。
3. 去重与降噪：重复规则只保留一份，措辞统一。

## 3. 实操步骤

```bash
# 1) 查看冲突块
git diff -- CLAUDE.md

# 2) 导出双方内容（便于并排对比）
git show :2:CLAUDE.md > /tmp/claude.ours.md
git show :3:CLAUDE.md > /tmp/claude.theirs.md

# 3) 编辑 CLAUDE.md 完成合并
# 建议先采用 theirs，再补回本地必要段落

# 4) 标记解决
git add CLAUDE.md
```

## 4. 合并后快速检查

```bash
# 应存在上游新增章节
rg -n "Work Approach: Orchestrator-First|Context Management" CLAUDE.md

# 如需保留本地中文规范，确认仍存在
rg -n "渐进式读写原则" CLAUDE.md
```
