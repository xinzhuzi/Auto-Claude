## 5. 合并策略

### 5.1 优先级

| 优先级 | 类型 | 策略 |
|--------|------|------|
| 🔴 P0 | XState 状态机重构 | 引入上游 |
| 🔴 P0 | Bug 修复 (#1853, #1847) | 引入上游 |
| 🟡 P1 | 本地独有模块 (workflow, novel) | 保留本地 |
| 🟡 P1 | IPC Handlers | 手动合并 |
| 🟢 P2 | 配置文件 | 保留本地配置 |

### 5.2 冲突解决顺序

1. **先引入上游 XState 重构**
   - State machines 目录
   - PR review state manager
   - 移除废弃的 TaskStateMachine

2. **保留本地独有功能**
   - `workflow/` 组件目录
   - `novel/` 组件和后端
   - `code-server` 相关
   - `skill` 相关
   - 道劫设置

3. **手动合并关键文件**
   - `ipc-handlers/index.ts` - 合并导出
   - `terminal/*.ts` - 合并逻辑
   - `stores/*.ts` - 合并状态
   - `package.json` - 合并依赖

### 5.3 冲突处理规则

| 文件类型 | 规则 |
|----------|------|
| `.ts/.tsx` (双方都有改) | 手动合并，优先上游 bug 修复 |
| `.ts/.tsx` (本地独有) | 保留本地 |
| `.ts/.tsx` (上游独有) | 引入上游 |
| `package.json` | 合并依赖，保留本地配置 |
| `docs/` 中文目录 | 保留本地 |
| `*.md` 文档 | 保留本地 |
