# 星月写作核心功能复刻计划

## 背景

在 Auto-Claude 项目的小说创作模块中，复刻星月写作（https://www.xingyuexiezuo.com/）的核心功能架构。

## ⚠️ 重要发现：星月写作工作流 ≠ Auto-Claude现有工作流

经过分析星月写作的实际界面，发现其工作流系统与 Auto-Claude 现有工作流有本质区别：

| 维度 | 星月写作 | Auto-Claude现有 |
|------|----------|-----------------|
| **界面** | 向导式表单 | 可视化节点画布 |
| **编排** | 预定义步骤，不可编辑 | 自由连接节点 |
| **参数** | 表单字段输入 | 节点属性面板 |
| **执行** | 分步/一键运行 | 流式执行节点 |
| **定位** | 小说专用生成模板 | 通用自动化工具 |

**结论**: 需要新建**小说专用工作流系统**，而非复用现有系统。

```
┌─────────────────────────────────────────────────────────────┐

│ 📋 工作流信息          │ 📝 输入参数          │ ⚙️ 执行模式 │

│ 描述内容...            │ 选择书籍 *           │ 支持分步    │
│                        │ 关联前文章节         │             │
│ 执行步骤:              │ 后续剧情走向         │ ○ 👣 分步  │
│ 1. 一键2万字...        │ 角色卡               │ ○ 🚀 一键  │
│                        │ 词条卡               │             │
│                        │ 关联备忘录           │ [开始执行]  │
│                        │ 补充信息             │             │
└─────────────────────────────────────────────────────────────┘
```

### 核心概念

1. **工作流 = 预定义的AI生成流程模板**
   - 每个工作流有固定的执行步骤
   - 用户只需填写参数，点击运行

2. **输入参数类型**:
   - `选择书籍` - 关联用户的作品
   - `关联前文章节` - 上下文引用
   - `角色卡/词条卡` - 素材库集成
   - `文本输入` - 剧情走向、补充信息等

3. **执行模式**:
   - 分步执行 - 逐步查看调整
   - 一键运行 - 自动完成全部

## 核心扩展方案

### 1. 小说专用工作流系统（新建）

**核心理念**: 向导式表单 + 预定义步骤模板，与小说项目深度绑定。

**新增类型定义** (`novel.ts`):

```typescript
// ===== 小说工作流系统 =====

export interface NovelWorkflow {
  id: string;
  name: string;
  description: string;
  author: string;
  authorId?: string;
  avatar?: string;
  rating: number;        // 评分 0-5
  usageCount: number;    // 使用次数
  category: WorkflowCategory;
  tags?: string[];
  steps: WorkflowStep[];
  inputParams: WorkflowInputParam[];
  isPublic: boolean;
  createdAt: string;
  updatedAt: string;
}

export type WorkflowCategory =
  | 'short-story'   // 短篇
  | 'long-story'    // 长篇
  | 'continuation'  // 续写
  | 'outline'       // 大纲
  | 'polish'        // 润色
  | 'character'     // 人物
  | 'world';        // 世界观

export interface WorkflowStep {
  id: string;
  name: string;
  description?: string;
  promptTemplate: string;    // 提示词模板
  outputType: 'text' | 'chapter' | 'outline' | 'character';
  maxTokens?: number;
}

export interface WorkflowInputParam {
  name: string;              // 字段名
  label: string;             // 显示标签
  type: InputParamType;
  required: boolean;
  defaultValue?: string;
  placeholder?: string;
  description?: string;
  options?: string[];        // select类型选项
  binding?: NovelFieldBinding;
}

export type InputParamType =
  | 'book'         // 书籍选择器
  | 'chapter'      // 章节选择器（多选）
  | 'character'    // 角色卡选择器
  | 'term'         // 词条卡选择器
  | 'memo'         // 备忘录关联
  | 'text'         // 文本输入
  | 'textarea'     // 多行文本
  | 'select'       // 下拉选择
  | 'number';      // 数字输入

export type NovelFieldBinding =
  | 'title'
  | 'genre'
  | 'theme'
  | 'outline'
  | 'chapters'
  | 'characters'
  | 'worldSettings';

// 工作流执行记录
export interface WorkflowExecution {
  id: string;
  workflowId: string;
  projectId: string;
  params: Record<string, unknown>;
  mode: 'step' | 'auto';
  status: 'pending' | 'running' | 'completed' | 'error';
  currentStep?: number;
  results: StepResult[];
  startedAt: string;
  completedAt?: string;
}

export interface StepResult {
  stepId: string;
  stepName: string;
  output: string;
  tokensUsed?: number;
  executedAt: string;
}
```

## 与 Auto-Claude 现有工作流的关系

| 系统 | 定位 | 用户 |
|------|------|------|
| **现有工作流** (`/workflow`) | 通用自动化工具 | 高级用户 |
| **小说工作流** (`/novel/workflow`) | 小说专用生成模板 | 小说创作者 |

两个系统**并存**，各有定位。小说工作流专注于：
- 开箱即用的生成模板
- 与小说项目深度绑定
- 简单的向导式交互
