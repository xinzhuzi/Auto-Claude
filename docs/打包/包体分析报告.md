## 🔴 发现的问题

### 问题 1: Windows 版本被打入 Mac 包 (19M 浪费)

```
code-server/lib/code-server-4.108.0-win  →  19M
```

**原因**: 打包配置没有排除其他平台的文件
**节省**: 19M

### 问题 2: node_modules 重复 (188M 浪费)

```
vscode/node_modules       →  188M
vscode/node_modules.asar  →  188M
```

**原因**: 同时存在解压版和 asar 打包版
**节省**: 188M

### 问题 3: code-server 内嵌 Node.js (106M)

```
code-server/lib/code-server-4.108.0/lib/node  →  106M
```

**说明**: code-server 自带了完整的 Node.js 运行时
**可能优化**: 如果 Electron 的 Node.js 版本兼容，可以复用

### 问题 4: Python 依赖过大 (330M)

主要大包:
| 包名 | 大小 | 是否必需 |
|------|------|---------|
| claude_agent_sdk | 172M | ✅ 必需 |
| grpc | 37M | ✅ 必需 |
| pandas | 27M | ❓ 可能不需要 |
| cryptography | 21M | ✅ 必需 |
| numpy | 12M | ❓ 可能不需要 |

## ✅ 优化建议

### 立即可做 (节省 ~207M)

1. **删除 Windows 版本 code-server** (-19M)
   ```bash
   # 在打包配置中排除
   "files": [
     "!**/code-server-*-win/**"
   ]
   ```

2. **删除重复的 node_modules** (-188M)
   ```bash
   # 只保留 asar 版本，删除解压版
   rm -rf code-server/lib/code-server-4.108.0/lib/vscode/node_modules
   ```

### 中期优化 (需要测试)

3. **精简 Python 依赖**
   - 检查 pandas 是否真的需要
   - 检查 numpy 是否真的需要
   - 可能节省: 40M+

4. **复用 Node.js 运行时**
   - 检查 Electron 的 Node.js 版本
   - 如果兼容，可以让 code-server 使用 Electron 的 Node.js
   - 可能节省: 106M

### 长期优化

5. **按需下载 code-server**
   - 首次启动时下载
   - 不打入包体
   - 可能节省: 781M

6. **按需下载 Python 依赖**
   - 使用虚拟环境
   - 首次启动时安装
   - 可能节省: 330M

## 📝 实施步骤

### ✅ 已完成的优化

#### 1. 平台感知的 code-server 打包 (`apps/frontend/scripts/package-with-python.cjs`)

`stageCodeServer` 函数现在会：
- 根据目标平台只复制对应的 code-server 版本
- Mac/Linux 打包：只复制 `code-server-4.108.0`
- Windows 打包：只复制 `code-server-4.108.0-win`
- **自动删除重复的 node_modules**（保留 node_modules.asar）

#### 2. 修改打包配置 (`apps/frontend/package.json`)

在 `extraResources` 的 `code-server` 配置中添加了排除规则作为备份保护。

#### 3. beforePack 钩子 (`apps/frontend/electron-builder.cjs`)

作为最后一道防线，验证并清理不匹配平台的文件。

### 🔧 使用方法

**方法 1: 使用打包脚本（推荐）**
```bash
# Mac 打包 (在 Mac/Linux 上)
./scripts/build-mac.sh

# Windows 打包 (在 Windows 上)
scripts\build-win.bat
```

**方法 2: 使用 npm 命令**
```bash
cd apps/frontend

# Mac 打包
npm run package:mac

# Windows 打包
npm run package:win
```

所有优化都在 `package-with-python.cjs` 中自动完成，无需手动操作。
