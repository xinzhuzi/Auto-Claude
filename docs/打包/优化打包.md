# Auto-Claude 打包优化指南

**最后更新**: 2026-01-27

---

## 📦 打包命令

```bash
# Mac 打包
./scripts/build-mac.sh
# 或
cd apps/frontend && npm run package:mac

# Windows 打包
scripts\build-win.bat
# 或
cd apps/frontend && npm run package:win
```

所有优化都在 `package-with-python.cjs` 中自动完成，无需手动操作。

---

## ✅ 已实现的优化

### 1. 平台感知的 code-server 打包

`apps/frontend/scripts/package-with-python.cjs` 中的 `stageCodeServer` 函数：

- Mac/Linux 打包：只复制 `code-server-4.108.0`
- Windows 打包：只复制 `code-server-4.108.0-win`
- 自动删除重复的 `node_modules`（保留 `node_modules.asar`）

### 2. 打包配置排除规则

`apps/frontend/package.json` 的 `extraResources` 配置：

```json
{
  "from": "code-server-staged/lib",
  "to": "code-server/lib",
  "filter": [
    "!**/.git",
    "!**/.DS_Store",
    "!**/code-server-*-win/**",
    "!**/vscode/node_modules/**"
  ]
}
```

### 3. beforePack 钩子

`apps/frontend/electron-builder.cjs` 作为最后一道防线，验证并清理不匹配平台的文件。

## 📊 优化效果

| 优化项 | 节省空间 |
|--------|----------|
| 只打包当前平台的 code-server | ~19M |
| 删除重复 node_modules | ~188M |
| **总计** | **~207M** |

优化后包体大小: **~1.3GB** (从 1.5GB 降低)

---

## 📁 包体结构

### 总体分布

| 目录 | 大小 | 占比 | 说明 |
|------|------|------|------|
| Resources/code-server | ~580M | 45% | VSCode 编辑器（优化后） |
| Resources/python-site-packages | 330M | 25% | Python 依赖 |
| Frameworks/Electron | 253M | 20% | Electron 框架 |
| Resources/app.asar | 114M | 9% | 应用代码 |
| Resources/python | 50M | 4% | Python 运行时 |

### code-server 结构（优化后）

```
code-server/
└── lib/
    └── code-server-4.108.0/           ~580M (Mac/Linux)
        ├── lib/
        │   ├── vscode/                ~420M
        │   │   ├── node_modules.asar  188M  ← 只保留这个
        │   │   ├── out/               125M
        │   │   └── extensions/        110M
        │   └── node                   106M
        └── node_modules/               44M
```
