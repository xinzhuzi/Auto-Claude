## 已实现的优化

### 1. 平台感知的 code-server 打包

`apps/frontend/scripts/package-with-python.cjs` 中的 `stageCodeServer` 函数：

```javascript
// 只复制当前平台的 code-server
for (const entry of entries) {
  if (entry.includes('-win')) {
    // Windows 版本
    if (platform !== 'win') {
      console.log(`[package] Skipping Windows code-server for ${platform} build`);
      continue;
    }
  } else if (entry.match(/^code-server-[\d.]+$/)) {
    // Mac/Linux 版本
    if (platform === 'win') {
      console.log(`[package] Skipping Mac/Linux code-server for ${platform} build`);
      continue;
    }
  }
  
  fs.cpSync(srcPath, destPath, { recursive: true, dereference: true });
}
```

### 2. node_modules 去重

源目录结构：
```
vscode/
├── node_modules/           # 真实目录 (~188MB)
└── node_modules.asar -> node_modules  # 符号链接
```

使用 `dereference: true` 复制后，两者都变成完整目录（重复）。

优化逻辑：
```javascript
// 保留 node_modules，删除 node_modules.asar
// Node.js 只能从 node_modules 目录加载模块
if (hasNodeModules && hasNodeModulesAsar) {
  console.log('[package] Removing duplicate node_modules.asar (keeping node_modules)...');
  fs.rmSync(nodeModulesAsar, { recursive: true, force: true });
  console.log('[package] Saved ~188MB by removing duplicate node_modules.asar');
} else if (!hasNodeModules && hasNodeModulesAsar) {
  // 如果只有 node_modules.asar，重命名为 node_modules
  console.log('[package] Renaming node_modules.asar to node_modules...');
  fs.renameSync(nodeModulesAsar, nodeModulesDir);
}
```

### 3. 打包配置排除规则

`apps/frontend/package.json` 的 `extraResources` 配置：

```json
{
  "from": "code-server-staged/lib",
  "to": "code-server/lib",
  "filter": [
    "!**/.git",
    "!**/.DS_Store",
    "!**/code-server-*-win/**",
    "!**/code-server-*-win"
  ]
}
```

**注意**: 不要排除 `node_modules`，否则会导致运行时错误：
```
Cannot find package '@microsoft/1ds-core-js'
```

### 4. beforePack 钩子

`apps/frontend/electron-builder.cjs` 作为最后一道防线：

```javascript
beforePack: async (context) => {
  const platform = context.electronPlatformName;
  
  // 验证并清理不匹配平台的文件
  for (const entry of entries) {
    if (entry.includes('-win') && platform !== 'win32') {
      console.log(`[beforePack] Removing unexpected Windows code-server...`);
      fs.rmSync(entryPath, { recursive: true, force: true });
    } else if (entry.match(/^code-server-[\d.]+$/) && platform === 'win32') {
      console.log(`[beforePack] Removing unexpected Mac/Linux code-server...`);
      fs.rmSync(entryPath, { recursive: true, force: true });
    }
  }
}
```

## 关键注意事项

### node_modules 必须保留

VS Code Server 的 `server-main.js` 在运行时需要动态加载依赖包：

```javascript
// server-main.js 中的 import
import '@microsoft/1ds-core-js';
import '@microsoft/1ds-post-js';
// ...
```

这些包存放在 `node_modules` 目录中。如果删除，会导致：
```
Cannot find package '@microsoft/1ds-core-js' imported from .../server-main.js
```

### node_modules.asar 不是真正的 asar

在源目录中，`node_modules.asar` 是指向 `node_modules` 的符号链接，不是 Electron 的 asar 归档文件。

Node.js 的模块解析只会查找 `node_modules` 目录，不会查找 `node_modules.asar`。
